**Domain:** astanabiz.com (root) — Astana POS lives on the root domain; MCBIZ continues at mcbiz.astanabiz.com.
**Project type:** Brochure site (SaaS product page) with WhatsApp + free trial as primary CTAs.

**Strategic direction:** **Astana POS is the software counterpart to MCBIZ. The two homepages mirror each other section-for-section — same rhythm, same patterns, same trust signals, same brand language — but every section's content is reoriented from hardware bundles to cloud software.**

## Strategic Positioning Note (read before designing)

In this version, Astana POS doesn't just *look like* MCBIZ — it **structurally mirrors** MCBIZ section-for-section. Open the two homepages in adjacent browser tabs and they should feel like two pages of the same brochure, one selling hardware bundles, the other selling software subscriptions. This is the strongest possible expression of the "family resemblance" strategy.

**MCBIZ → Astana POS mapping (12 sections):**

| # | MCBIZ section | Astana POS counterpart |
|---|---|---|
| 1 | Hero: "MCBIZ pilihan juruwang anda" + terminal photo + "Bermula dari RM490" + 3 trust bullets | Hero: "Astana POS — cloud juruwang anda" + **live dashboard** + "Cuba percuma 14 hari" + 3 trust bullets |
| 2 | Live catalogue marquee (terminals, bundles, customer logos) | Live module marquee (6 cloud modules + customer logos) |
| 3 | "Satu sistem. Dua belas industri. Tiada had." 12-industry tab | "Satu cloud. Dua belas industri. Tiada had." — same 12 industries, same tab pattern |

| 12 | Footer — logo + product/syarikat columns + trademark badges | **Identical footer** + **mandatory sibling-brand pill linking to MCBIZ** |

**The hardware cross-sell moment.** Because Astana POS doesn't sell hardware, the equivalent of MCBIZ's product grid becomes the *subscription pricing* section — but immediately below it, a short cross-sell band ("Perlukan perkakasan? Lihat MCBIZ →") that has no MCBIZ-side equivalent. This is the one section where the two sites diverge functionally, and it's a strategic asset — every Astana POS visitor sees the path to hardware, every MCBIZ visitor already has it.

The client brief — *"look more modern and gain trust from customers to subscribe"* — is answered by **direct trust transfer**: visitors recognise the brand language and section rhythm from MCBIZ on first scroll, so the 6 years of trust MCBIZ has built transfer to Astana POS on contact.

## Reference Sites Analysis

| Site | What to borrow | What to NOT borrow |
|---|---|---|
| **salesplay.com/pos/malaysia/** | Industry coverage breadth, Malaysian context (SST/MyInvois) | Elementor/WordPress feel, generic stock photography, feature-tile soup |
| **loyverse.com** | App screenshots front and centre, multi-language switcher | Visual blandness, generic SaaS blue, no Malaysian context |
| **mcbiz.astanabiz.com** (sibling brand — STRUCTURAL TEMPLATE) | **Section rhythm and order — all 12 sections mirrored**, Syne display font, gradient greens, BM/EN toggle, WhatsApp CTA pattern, footer treatment, trust signals, "Perjalanan Astana" timeline (shared history), "Dengan nombor" counter stats (same ecosystem) | Hardware product cards (replaced with subscription tiers), "Tambah ke Troli" e-commerce flow (replaced with WhatsApp + Cuba Percuma), per-unit RM pricing for terminals (replaced with monthly RM subscription pricing) |

**Distinctive move within the shared brand language:** the *live-feeling dashboard hero* — rendered Astana POS dashboard at the top with animated mini-cards (sales ticking up, new order chip sliding in, low-stock alert flashing). MCBIZ's hero shows a *static* terminal photo with a small dashboard summary card. Astana POS's hero replaces the terminal photo with a *live software view* of that same dashboard, fully animated. This is how the two heroes differ while staying in the same composition.

## Important Context Notes

- **Bilingual is non-trivial.** BM as primary, EN toggle. Translation files from day one. No hardcoded strings.
- **Subscription framing wins.** Hero CTAs lead with "Cuba Percuma 14 Hari" — the trial offer that maps to "Bermula dari RM490" on MCBIZ. Free trial is the closest software-equivalent to MCBIZ's price anchor.
- **No e-commerce on the site.** Sign-ups route to `hub.astanabiz.com/registration_form`. The pricing section is for tier comparison + WhatsApp/registration redirect only — no cart, no checkout.
- **Blog/news section** requested but defer to Phase 3 (MDX-based, no separate CMS).
- **Mobile PageSpeed matters.** Live dashboard animations must be DOM + Framer Motion, not video.
- **WhatsApp** uses the same number as MCBIZ (`+601159918214`) — confirm with client; prefill text differs so support routes correctly.
- **Astana POS is on Google Play Store** in 177 countries. Play Store badge appears prominently.
- **12 sections is intentional.** It mirrors MCBIZ's section count exactly. Don't compress — that defeats the structural-mirror strategy.

## Build Phases

### Phase 1 — Foundation & Homepage (12 sections)

The full 12-section homepage. **This is a larger Phase 1 than V1's 6-section plan — and that's the entire point of V2.** The structural mirror has to be complete from launch, otherwise the family-resemblance strategy is invisible.

**Tasks:**
1. Install dependencies (Framer Motion, react-hook-form, zod, react-calendly).
2. Add shadcn components (button, dialog, accordion, tabs, separator, sheet).
3. Replace `app/globals.css` with the full block from design.md.
4. Load Syne + Satoshi via `next/font/local` (Fontshare WOFF2 in `public/fonts/`).
5. Render global gradient-mesh atmosphere in `app/layout.tsx`.
6. Set up `src/i18n/` with `en.ts` + `ms.ts` + `LocaleContext.tsx`. Default to BM.
7. Build shared components: Navbar, Footer, CTAButton, SectionWrapper, LanguageToggle, WhatsAppFloat, LiveDashboard, Marquee, IndustryTabs, TimelineRail, Counter.
8. Build all **12 homepage sections** (full spec in initial_prompt.md):
   1. **Hero** (mirrors MCBIZ hero; live dashboard instead of static terminal)
   2. **Module Marquee Strip** (mirrors MCBIZ catalogue marquee; 6 cloud modules + customer logos)
   3. **"Satu cloud. Dua belas industri."** (mirrors MCBIZ 12-industry tab section)
   4. **Subscription Pricing Tier Cards** (mirrors MCBIZ product cards section — software product, not hardware)
   5. **Hardware Cross-Sell Band** (V2-only — links out to MCBIZ for terminals)
   6. **"Perjalanan Astana" 6-year timeline** (mirrors MCBIZ timeline exactly — shared history)
   7. **"Lima sebab peniaga pilih cloud kami."** (mirrors MCBIZ 5-reason grid)
   8. **"Tiga langkah ke jualan pintar."** (mirrors MCBIZ 3-step how-it-works)
   9. **"Dengan nombor" counter stats** (mirrors MCBIZ stats — same ecosystem)
   10. **Testimonials** (mirrors MCBIZ testimonial layout, different SME owners)
   11. **Final CTA band** (mirrors MCBIZ closer)
   12. **Footer** (mirrors MCBIZ footer with sibling-brand pill)

**Deliverable:** Homepage live on `localhost:3000`, bilingual working, mobile responsive at 375/768/1280, `bunx tsc --noEmit` passing, live dashboard animating smoothly, all 12 sections present and matching MCBIZ rhythm side-by-side.
